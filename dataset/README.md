# Datasets

Small public teaching datasets used by the notebooks in this course. They remain under the terms of their original sources.

| File | Used in | Task |
|---|---|---|
| `Data.csv` | 1. Data Preprocessing | Handling missing values and categorical features |
| `Salary_Data.csv` | 2. Regression | Simple linear regression (salary vs. years of experience) |
| `50_Startups.csv` | 2. Regression | Multiple linear regression and backward elimination (startup profit) |
| `Position_Salaries.csv` | 2. Regression | Polynomial, SVR, decision tree and random forest regression |
| `Social_Network_Ads.csv` | 3. Classification, 5. Dimensionality Reduction, 7. Model Selection | Binary classification (purchase prediction) |
| `PastHires.csv` | 3. Classification | Decision tree classification (hiring decisions) |
| `Mall_Customers.csv` | 4. Clustering | Customer segmentation |
| `Wine.csv` | 5. Dimensionality Reduction | PCA and LDA on wine chemical features |
| `Churn_Modelling.csv` | 6. Neural Networks, 7. Model Selection | Customer churn prediction |
| `Market_Basket_Optimisation.csv` | Exercise | Association rule learning |
| `Restaurant_Reviews.tsv` | Exercise | Text classification (sentiment of reviews) |
